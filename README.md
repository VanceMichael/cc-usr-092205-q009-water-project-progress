# 水利投资实物量核对

核对水利工程投资、现场实物量和关键节点进度。核心立场：进度按**施工段和工程量**组织，付款额（含预付款）是资金行为，不得代替完成量。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例（金额与工程量均为示意值）。`src/domain.js` 统一加载资料并做结构校验：角色分权、证据链、月结要素、调拨平衡、单价脱敏等不变量不成立即抛错。

## 领域规则

- **三角色分权**：承包商提交本标段事实，监理确认实物量，财务只处理已批准款项；三者不能互相代签。
- **证据链对应**：批复概算、合同清单、北斗车辆记录、监理计量、现场影像、设计变更、付款凭证逐环节对应，计量与支付落到清单子目。
- **不重复确认**：跨标段材料调拨只在实际消耗标段计量一次；返工量不新增计量；迟到签证不回填以前账期。
- **月结四要素**：资金与实物量偏差、影响冬灌/通水节点的关键线路、责任标段、下一周期可追回的工程量——供项目负责人调配资源，而非事后解释百分比。
- **公开脱敏**：对外版本隐藏合同敏感单价与身份信息。

## 当前领域事实

- 前8个月全国完成水利建设投资6903亿元，同期实施各类水利项目3.8万个并新开工多项重大工程。
- 青铜峡灌区项目需在10月底前完成部分渠道砌护以保障冬灌；部分标段已支付预付款，但砌护实物进度仍可能赶不上冬灌，月报“投资与进度同步增长”的口径与实物量核对存在偏差。

## 本地校验

`npm test` 运行结构校验与规则测试（含负例：缺角色、调拨不平、单价泄露均拒绝）。仓库不保存账号、密钥、连接串或真实身份资料。
