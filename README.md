# 水利投资实物量核对

核对水利工程投资、现场实物量和关键节点进度。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。读取模块统一加载这些资料，并校验领域标识、版本、参与方、事实、约束、角色职责、凭证来源、核对规则和月结输出等必要字段。

当前资料反映以下领域事实：

- 前8个月全国完成水利建设投资6903亿元
- 同期实施各类水利项目3.8万个并新开工多项重大工程
- 青铜峡灌区项目需在10月底前完成部分渠道砌护以保障冬灌
- 部分标段已支付预付款但对应渠道砌护实物量尚未形成
- 按付款额统计的月报显示投资与进度同步增长，与现场实物量存在偏差

## 角色职责

承包商提交本标段事实，监理确认实物量，财务只处理已批准款项，三类角色不得互相代签；建设单位项目负责人依据月结结果调整资源。

## 凭证对应

批复概算、合同清单、北斗车辆记录、监理计量、现场影像、设计变更和付款凭证七类凭证彼此对应。进度按施工段和工程量组织，付款额不得代替完成量，预付款不计入完成实物量。

## 核对规则

- 跨标段材料调拨、返工及迟到签证只确认一次，不得重复计量
- 公开信息隐藏合同敏感单价

## 月结输出

每次月结明确资金与实物量的偏差、影响冬灌或通水节点的关键线路、责任标段和下一周期可追回的工程量，项目负责人据此调整资源而非事后解释百分比。

## 本地校验

运行项目自带测试可确认样例资料符合约定。仓库不保存账号、密钥、连接串或真实身份资料。
